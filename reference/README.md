# Original workspace reference

The main repository contains the copied code, dataset and results from the completed Gen Academy experiment, plus the new submission presentation and documentation.

`gen-academy-workspace/` preserves the original versions of documents and code that were subsequently improved in this repository, along with the small adapter configuration and training-metrics records. These are historical snapshots, not the current entry points. Use the root README and scripts for the current workflow.

`COPY_MANIFEST.json` records source-file hashes and copy decisions. Credentials, environments, model weights and cache files are excluded from GitHub. Raw SDK records and the original submission ZIP were copied locally and remain ignored. The root ATTRIBUTION.md identifies the public course source.

Absolute local project paths in archived text and copied console logs are replaced with project-root placeholders for publication. Numeric results and source code behavior are unchanged.
